# Security policy

`hottubctl` handles a cloud username and password and can change heated water
equipment. Keep credentials in a private mode-`0600` config. Report
vulnerabilities privately through GitHub's security-advisory feature instead of
opening a public issue with credentials, spa IDs, raw responses, or exploit
details.

Never include real account credentials, spa names or identifiers, session data,
or private automation configuration in a report.

This project uses an unofficial cloud integration and cannot provide safety,
availability, or security guarantees for SmartTub or connected equipment.
